# Roban2 / S17：旧 SDK 头部 yaw / pitch 控制

2026-11-04：在 `/home/lab/Lejulab_ARM/scripts/head_sdk_pose/` 原有 pitch 控制基础上增加 `--yaw-deg`。目标为绝对关节角，单位度；省略 yaw 时仍保持启动时的 yaw，pitch 默认仍为 35°。

## 使用

已有正常运行的机器人硬件及 `amp` 或 `heft_pico` 主控时，在下位机终端运行：

```bash
cd /home/lab/Lejulab_ARM

# 仅查看参数，不连接机器人、不初始化运动 SDK
bash scripts/head_sdk_pose/head_sdk_pose.sh --help

# 只读检查反馈和控制器，不发布轨迹
bash scripts/head_sdk_pose/head_sdk_pose.sh

# pitch 下俯 20°，yaw 移至绝对角 20°；持续保持至 Ctrl+C
bash scripts/head_sdk_pose/head_sdk_pose.sh --execute --pitch-deg 20 --yaw-deg 20

# yaw 移至负角
bash scripts/head_sdk_pose/head_sdk_pose.sh --execute --pitch-deg 20 --yaw-deg -20

# yaw 回到零度；0 是明确目标，不表示保持当前值
bash scripts/head_sdk_pose/head_sdk_pose.sh --execute --pitch-deg 20 --yaw-deg 0

# 不指定 yaw，沿用原先保持启动 yaw 的行为
bash scripts/head_sdk_pose/head_sdk_pose.sh --execute --pitch-deg 20

# 运动完成后保持 10 秒，再停止发布
bash scripts/head_sdk_pose/head_sdk_pose.sh --execute --pitch-deg 20 --yaw-deg 20 --hold-seconds 10
```

yaw 的正负沿用机器人原有 SDK 关节定义。此次只进行了离线测试及下位机适配器参数检查，未通过真实运动确认正负角对应的左右方向。

`Ctrl+C` 停止发布；停发后的姿态由原控制器处理。`--hold-seconds 0` 为持续保持（默认），有限保持允许 3～86400 秒。单实例锁会拒绝本工具的重复执行；该锁不能拦截其他头部发布程序。

## 参数与控制

- `--yaw-deg`：−90°～90°，包含端点；默认保持 SDK 初始化后读取的当前 yaw。
- `--pitch-deg`：−20°～45°，包含端点；下俯为正，默认 35°。
- `--duration`：2～120 秒，默认 7 秒。两个轴使用同一条平滑插值曲线；按较大角度跨度自动延长时长，保证每轴参考速度不超过 8°/s。跨度很大时，自动延长后的实际时长可以超过 120 秒。
- 发布频率为 50 Hz，使用旧 SDK `RobanVRAPI::publishHeadJointCmd()` 向 `/rt/head_trajectory` 发送 `[yaw, pitch]`，单位弧度；不发送身体关节指令。
- 省略 yaw 时保留原来的 yaw 偏移保护；指定 yaw 时允许其按目标转动。两个轴均检查明显无响应，运动结束 3 秒后均须在各自目标 ±2° 内，并在保持期间持续检查。
- 保留反馈范围、23 关节消息时间戳/接收时间、控制器状态及 SDK 回复检查；反馈超过 0.25 秒或发布循环间隔超过 0.15 秒时停止。

反馈新鲜度检查基于 DDS 消息；若底层用新时间戳重复发布缓存电机数据，本工具不能据此识别每台电机是否仍有真实反馈。该限制未因本次 yaw 参数扩展而改变。

## 环境和记录

Shell 入口转发所有参数，无需改动；原 C++ 适配器已支持两个头部关节及其速度，因此本次修改 Python 控制逻辑、测试和本文档。执行时如果适配器缺失或 C++ 源码较新，会自动编译；也可用 `bash scripts/head_sdk_pose/head_sdk_pose.sh --build` 单独编译。

依赖下位机现有 Python CycloneDDS 和旧 SDK，`LEJULAB_PROJECT_ROOT` 默认 `/home/lab/Lejulab_ARM`。Python DDS 和 C++ SDK 使用独立进程；只对当前进程关闭 DDS 共享内存，保留原网络接口/发现设置。

每次运行写入 `scripts/head_sdk_pose/validation/时间_进程号_编号/`：

- `session_status.json`：请求/解析后的 yaw 目标、pitch 目标、`yaw_mode`、实际运动时长、实测角、到位状态、退出原因和发送帧数。
- `samples.jsonl`：约 5 Hz 的双轴参考与反馈角度。

`--output-dir` 可指定记录父目录。不加 `--execute` 时不初始化运动 SDK、不发布轨迹。

## 离线验证

在本目录运行 `python3 -m unittest -v test_head_sdk_pose.py`。下位机可设置 `HEAD_SDK_BRIDGE` 指向已有适配器，并配置其动态库路径，额外检查 C++ `CHECK` 参数保护；该测试不调用 `INIT`，且验证未初始化时 `PUB` 被拒绝。

覆盖 yaw 正负角、零度、±90°端点、非法数值、双轴平滑与限速、单轴无响应、到位/保持误差，以及原有 pitch、只读、反馈过期、控制器异常、循环超时等回归场景。模拟测试不代表真实运动精度已经验证。
