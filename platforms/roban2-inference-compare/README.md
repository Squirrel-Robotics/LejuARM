# Roban-2 ACT 运动对比网页

本地地址：<http://127.0.0.1:8766/>。启动：

```bash
bash "/media/lsj/EXTERNAL_USB/Roban-Ubuntu/启动ACT仿真真机对比网页.sh"
```

同一命令末尾可加 `status` 或 `stop`，只影响本网页服务。

局域网内其他电脑可以打开 <http://192.168.110.41:8766/>（2026-11-03 核验的本机 Wi-Fi 地址）。启动和 `status` 命令会显示当前局域网地址，换网络或 DHCP 地址变化后以该输出为准。网页、模型、数据接口和相机图片均通过这台电脑的 8766 端口提供，其他电脑无需连接机器人或安装 Python。

页面默认加载最新有运动日志的实机运行。可选择历史记录、播放/暂停、逐帧前后移动、拖动时间轴、选择关节、跳到停止前两秒、切换四种参考来源及导出 CSV。勾选“跟随最新推理”后，每秒检查当前运行日志，并自动发现新运行。界面无机器人控制按钮，也不启动 ACT。

左侧展示 ACT 模型目标、上位机限速后候选、下位机已接收目标或 HEFT 已发布参考；右侧使用真实编码器反馈驱动同一 S17 + Revo-2 模型。数据按记录的实际时间轴对照，策略时间单独显示。ACK 依据本机接收时刻关联，不使用未来确认。实际跟踪误差使用每条 ACK 中的同一 native_reference 内参考与实测角，和模型目标偏差分开。记录结束不外推下一段动作。

这是运动学重建，不是重新执行 MuJoCo 接触仿真。底座固定，头部使用本次初始编码器快照，无法重建重新设零后的绝对光轴。手指沿用现有仿真的通道到模型范围映射，仅用于形态示意；下面六通道条形图保留原始 SDK 数值。桌面与料箱来自当前仿真 XML；未定位真实袋子，不生成袋子随手运动。

运行时相机复用 8765 观察台的共享缓存，图像与落盘轨迹有显示时差。历史记录只显示本次保存的相机采样照片并标明照片年龄，不能当作连续实机视频。缺失反馈保持未知，不以零替代。日志尾部未完成的 JSON 行会等待后续补全；读取是增量式，最多缓存三条运行，不修改原始记录。

`config.json` 指定已经核对存在的 v75 运行目录、原观察台模型资产和仿真 XML。网页使用现有本地 Three.js，无 CDN 依赖。服务监听 0.0.0.0:8766，可同时通过本机地址和局域网地址访问；无需安装额外 Python 包，也不会 SSH 登录机器人或创建 DDS 发布者。

测试：`python3 -m unittest discover -s tests -v`。原 8765 观察台和 46227 回放服务独立保留。
